# village - the 3D overworld. Layout, ground and props: the VS1 village (assets/vs1_art/, docs/SLICE_VS1_ART.md),

#      a solid footprint of w x h tiles (after rotation) is centred on (x, y)
# Layout rule (VS1, frame budget): houses along the road >= 14 tiles apart, so the field camera never frames
# more than three houses at once.
# entity <id> npc   <look> <x> <y> <facing> talk <script> [patrol <dx> <dy> <len>] [if <cond...>]
# entity <id> enemy <look> <x> <y> <facing> <encounter> [patrol <dx> <dy> <len>] [after <id> [<id>]] [win <flag>] [if <cond...>]
#      looks: slime -> skeleton warrior, guard -> skeleton mage, mage -> Wren (the Mage), smith -> Brom (the Barbarian)
#      talk: the script A runs (romdisk/scripts/village.txt); touching an NPC never starts a battle (slice 3D-5)
#      win: the quest flag set when this entity's battle is won;  if: the rest of the line is a condition
