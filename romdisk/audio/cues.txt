# cues.txt - every sound the game can make (slice 3D-7, docs/NEXT_SLICE_SOUND_SAVE.md 6.1). Loaded at boot by
# src/audio.cpp; checked by tools/audio/lint_cues.py (same rules, same messages). Files are under /rd/audio/.
#
#   music  <name> loop|once <file> <vol> [<fade_out> <fade_in>]   a track on the music stream ("once": a sting).
#                                                              fades in ticks (default 20 20): how fast the track
#                                                              before it leaves and this one arrives when an event
#                                                              starts it
#   sfx    <name> <file> <vol> <prio> <min_gap> [flags]        an effect: vol 0-255, prio 1-9 (9 = never dropped for a
#                                                              lower one), min_gap = ticks before it may play again
#                                                              flags: pan_actor (battle cues pan with the actor)
#   alias  <event> <cue>                                       an event name the game fires -> a cue above
#   silent <event>                                             an event that makes no sound, on purpose
#
# The game fires event names (eng::audio_event): "music_<name>" starts music <name>, "sting_<name>" plays the
# once-track <name>, anything else is an sfx name; an alias overrides all three.
