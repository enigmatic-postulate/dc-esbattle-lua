# village.txt - the village's scripts (slice 3D-5: "Talk to Wren"; slice 3D-6: the gate, the intro). GDD 7.4 / Appendix A.
# Compiled at boot by src/script.cpp into fixed pools (with barrow.txt and ending.txt: romdisk/maps/maps.txt); checked by
# tools/dialog/lint.py (tests/dialog, tests/barrow). The GDD Appendix A lines are kept verbatim; every change is marked
# "# slice 3D-5" or "# slice 3D-6" with its reason:
#   AD5  the stage-0 report branch also teaches Fireball (a GDD script bug: that route never did)
#   AD8  data directives: @flags, @marker (and speakers.txt)
#   D1   one GDD page split in two: the supplied pixel font is wider than the GDD's stand-in (page fit)
#   S16  emotes and gestures (emote / anim commands; no dialogue line changes)
#   S17  checkpoint ids (c1, c2, rest) name the checkpoint in the traces; the behaviour is the GDD's
#   slice 3D-6 undoes slice 3D-5's AD3 (the Warden on the east road), AD4 (Corwin's lines rewritten), AD6 (stage 6 =
#   the end) and AD7 (GAME OVER): Corwin guards the gate, the Warden is the barrow's (barrow.txt), the ending is a
#   script (ending.txt), a lost battle shows the death screen.

@flags patrol_a patrol_b skill_fire has_token talked_brom brom_refill gate_open       # slice 3D-5 (AD8); 3D-6: gate_open
@marker wren ! stage == 0 || stage == 2                                                  # slice 3D-5 (AD8)
@marker brom ... !talked_brom || stage >= 3 && !brom_refill                              # slice 3D-5 (AD8)
@marker corwin ! stage == 3                                                              # slice 3D-6: GDD App. B (S3)

@script new_game                  # slice 3D-5: run at a new game (the host harness starts in the field: no intro)
  objective "Speak with Wren"
  end

@script intro skip                # GDD App. A: the intro cutscene (slice 3D-6: after T2; Start skips it)
  letterbox on
  cam arrival 0
  place rowan 0 15 right          # slice 3D-6: the spawn (C0) is inside the gate: he starts outside it
  move rowan 3 15
  wait 20
  emote wren !
  anim wren interact
  cam overview 30
  wait 20                         # slice 3D-6: a beat on the overview before the bars go
  letterbox off
  objective "Speak with Wren"
  end

@script wren_main
@if stage == 0 && patrol_a + patrol_b == 2
  wren(worried): You fought them already? Both patrols? Then you know.
  give skill fireball                                     # slice 3D-5 (AD5)
  sys: Rowan learned FIREBALL.                            # slice 3D-5 (AD5)
  goto report
@elif stage == 0
  emote wren !                                            # slice 3D-5 (S16)
  wren: Oh! A knight. A real one. Thank the stars.
  wren(worried): The dead are walking again.|Two patrols came over the hill last night,
  wren(worried): and the old barrow gate is humming.
:ask
  choice "I will deal with them." -> accept | "Tell me more." -> lore
         | cancel "Not now." -> later
@elif stage == 1
  wren: Skeletons left: the counter says it all. Fire burns them, and burning keeps going.
  end
@elif stage == 2
:report
  wren(happy): Both patrols? You're quicker than my kettle.
  anim wren use_item                                      # slice 3D-5 (S16)
  wren: Take this token - Corwin will let you pass. And hold still...
  give token
  set max_hp 30
  heal
  sys: Wren's blessing! Max HP +10, fully healed.
  set stage 3
  objective "Show the token to Corwin"
  checkpoint c2                                           # slice 3D-5 (S17: id)
  end
@elif stage >= 3 && stage < 7
  wren: Corwin is waiting at the east road. Be careful in the barrow.
  end
@else
  wren(happy): Hollowmere sleeps easy tonight. Thanks to you.
  end
@end
:lore
  wren(worried): Long ago a guardian was bound under the barrow.        # slice 3D-5 (D1: the GDD page, split in two)
  wren(worried): The Bone Warden. He keeps the dead asleep.             # slice 3D-5 (D1)
  wren(worried): Something cracked his seal.
  goto ask
:accept
  set stage 1
  give skill fireball
  anim wren use_item                                      # slice 3D-5 (S16)
  wren(happy): Then take this. Burn the bones, not the barns.
  sys: Rowan learned FIREBALL.
  objective "Defeat the skeleton patrols ({patrols}/2)"   # slice 3D-5: the live counter (GDD: "(0/2)", App. B: "(n/2)")
  checkpoint c1                                           # slice 3D-5 (S17: id)
  end
:later
  wren: Come back before they reach the houses. Please.
  end

@script brom_main                                         # GDD Appendix A
@if !talked_brom
  anim brom use_item                                      # slice 3D-5 (S16)
  brom: Ho! A knight, and a rusty one. Here - three potions. Mind the cork, it bites.
  emote rowan sweat                                       # slice 3D-5 (S16)
  rowan: ...Thank you.
  brom: Don't thank me. Come back alive and buy a new helmet.
  give potions 3
  flag talked_brom
  end
@else
  brom: Need a rest? My fire's warm and my stew is only slightly alarming.
  choice "Rest (full heal)" -> rest | cancel "Later." -> bye
:rest
  fade out 20
  heal
  @if stage >= 3 && !brom_refill
     give potions 3
     flag brom_refill
     sys: Potions refilled.
  @end
  checkpoint rest                                         # slice 3D-5 (S17: id)
  fade in 20
  brom: Good as new. Well. Good as used.
  end
:bye
  brom: The fire's lit whenever you need it.               # slice 3D-5 (GDD 7.3: the "no" branch says how to come back)
  end
@end

@script corwin_block                                      # GDD App. A: the trigger on the east road while !gate_open
  move corwin 38 14 | face rowan corwin                   # slice 3D-6: he steps into the road (GDD 9.3 "Corwin steps in")
  face corwin rowan
  move rowan -1 0                                         # walked back one tile
  corwin: Road's closed. Nobody goes near the barrow, not with those things about.
  corwin: If Wren vouches for you, that's different.
  move corwin 37 13                                       # slice 3D-6: back to his post
  face corwin left
  end

@script corwin_main                                       # GDD App. A
@if stage == 3 && has_token && !gate_open                 # slice 3D-6: + stage == 3 (the same state: the lint's stage check)
  corwin: Wren's token. Well then.
  corwin(worried): When the old thing gathers the dark, get your shield up. Trust me.
  move corwin 38 13                                       # slice 3D-6: (37,12) is inside the VS1 house: he steps aside north-east
  face corwin left
  flag gate_open
  set stage 4
  sys: The east road is open.
  objective "Enter the Barrow"
@elif gate_open
  corwin: Shield up when it gathers the dark. Go on.
@else
  corwin: Nobody goes east. Talk to Wren if you must.
@end
  end

@script after_battle                                      # slice 3D-5: run after every won battle (slice 3D-6: the patrols only;
@if stage == 1 && patrol_a + patrol_b == 2                #   the Warden's battle is the barrow's script and the ending follows it)
  set stage 2
  objective "Report to Wren"
  sys: Both patrols are down. Report to Wren.
@end
  end
